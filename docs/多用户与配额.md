# 多用户、限速与配额

## 认证模型

服务端切到 `auth.method = "user"` 后，认证从「全局一个 token」变成「每户一个 token」：

```toml
# 服务端
auth.method = "user"
auth.userFile = "./users.json"
```

```toml
# 客户端
user = "alice"
[auth]
method = "user"
token = "sk_xxxx"
```

校验逻辑在 `pkg/auth/userauth.go`：

- `VerifyLogin`：按 `login.User` 查库，用该用户的 token 算 `md5(token+timestamp)`，常量时间比较；顺带校验启用状态、到期时间、流量配额；
- `VerifyPing` / `VerifyNewWorkConn`：协议里不带用户名，因此对所有启用用户做一次比对（用户数很小，开销可忽略）。**服务端开了 `additionalScopes` 就必须让客户端也开**，否则这些报文没有签名会被拒——默认建议留空。

> 每户 token 不同 ⇒ 两端无法共享传输密钥，控制通道的 token 加密层在该模式下不启用；机密性由 `transport.tls.force = true` 保证。

## 用户库

`users.json`（原子写：先写 `.tmp` 再 rename），字段：

```json
{
  "user": "alice",
  "token": "sk_xxxx",
  "enabled": true,
  "maxProxies": 5,
  "bandwidthLimitKbps": 10240,
  "trafficQuotaBytes": 10737418240,
  "createdAt": 1795593441,
  "expireAt": 0,
  "lastSeenAt": 1795593769,
  "note": "客户 A",
  "trafficIn": 582,
  "trafficOut": 51244
}
```

默认每 30 秒刷盘一次（`Store.AutoSave`），进程退出前也会落盘。

## 限速：服务端强制

两处限额取**更小值**：

1. 用户级 `bandwidthLimitKbps`（管理员定，客户端改不了）
2. 隧道级 `transport.bandwidthLimit`（客户端自己声明，仅当 `bandwidthLimitMode = "server"` 时在服务端生效）

实现：`server/proxy/proxy.go` 的 `NewProxy` 里创建 `rate.Limiter` 注入 `BaseProxy.limiter`，在 `join` 时同时限制上下行。

换算：`Kbps × 1024 ÷ 8 = 字节/秒`。例：`1024 Kbps → 131072 B/s ≈ 128 KB/s`，拉 1 MB 约 8 秒（实测 7.3 秒）。

## 流量与配额

- 记账：`pkg/metrics/mem` 在 `AddTrafficIn/Out` 里通过 `UserTrafficHook` 回调，把字节数加到对应用户账本；
- 统计：面板「用户」页显示今日上下行、累计流量；
- 配额：`trafficIn + trafficOut >= trafficQuotaBytes` 时拒绝登录（`login rejected for user [x]: traffic quota exceeded`）；
- 清零：面板「清空流量」按钮，或 `POST /api/v2/users/{user}/traffic`。

## 隧道数

`maxProxies` 按用户计，每次 `NewProxy` 时用 `mem.StatsCollector.ProxyCountByUser()` 比对，超限返回：

```
user [alice] reached the max proxy count limit (5)
```

## API 速查

```bash
AUTH='admin:密码'
B="http://1.2.3.4:7500"

curl -u "$AUTH" "$B/api/v2/users"
curl -u "$AUTH" -X POST "$B/api/v2/users" -H 'Content-Type: application/json' \
  -d '{"user":"bob","maxProxies":5,"bandwidthLimitKbps":10240,"trafficQuotaBytes":0,"expireAt":0,"note":""}'
curl -u "$AUTH" -X PUT "$B/api/v2/users/bob" -H 'Content-Type: application/json' \
  -d '{"bandwidthLimitKbps":20480}'
curl -u "$AUTH" -X POST "$B/api/v2/users/bob/token"
curl -u "$AUTH" -X DELETE "$B/api/v2/users/bob"
```

响应统一信封：`{"code":200,"msg":"success","data":...}`；错误时 HTTP 状态码等于 `code`，`msg` 是中文原因。
