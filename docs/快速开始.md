# 快速开始

## 1. 装服务端

有公网 IP 的机器（VPS / 云主机 / 独立服务器）上：

```bash
curl -fsSL https://raw.githubusercontent.com/scaryburial/sakura-tunnel/main/install.sh | sudo bash
```

装完会打印：

```
控制台：  http://1.2.3.4:7500/
账号：    admin
密码：    xxxxxxxxxxxxxx
接入端口：7443（客户端连接用）
```

记下密码，用浏览器打开控制台。

> 云厂商安全组记得放行 `7443/tcp`、`7500/tcp`，以及你打算暴露的远程端口段（默认 6000-6999、17000-17999）。

## 2. 建一个租户

控制台 → **用户** → **新建用户**：

| 字段 | 说明 |
|---|---|
| 用户名 | 2-32 位字母数字下划线点横线 |
| 最大隧道数 | 0 = 不限 |
| 限速 (Kbps) | 0 = 不限；10240 = 10 Mbps |
| 流量配额 (GB) | 0 = 不限；超额后拒绝登录 |
| 到期时间 | 留空 = 永久 |

保存后会弹一次 `sk_xxxx` 密钥，**关掉就不再显示**（可以随时「重置密钥」）。

## 3. 让对方接入

在用户那一行点 **一键接入**，复制对应系统的命令：

```bash
# Linux
curl -fsSL http://1.2.3.4:7500/i/sk_xxxx | bash

# Windows（PowerShell）
powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr -useb http://1.2.3.4:7500/w/sk_xxxx | iex"
```

对方执行完，本机 `127.0.0.1:22` 就被映射到服务器 `6000`：

```bash
ssh -p 6000 user@1.2.3.4
```

想改成转发别的端口：

```bash
curl -fsSL http://1.2.3.4:7500/i/sk_xxxx | bash -s -- --local 127.0.0.1:8080 --remote-port 6001
```

## 4. 手工配置客户端（可选）

不想用一键脚本就自己写 `client.toml`，照 `examples/client.toml` 改：

```toml
serverAddr = "1.2.3.4"
serverPort = 7443
user = "alice"

[auth]
method = "user"
token = "sk_xxxx"

[transport.tls]
enable = true

[[proxies]]
name = "alice-web"
type = "tcp"
localIP = "127.0.0.1"
localPort = 8080
remotePort = 6001
```

```bash
./sakura client -c client.toml
```

## 5. 排障

| 现象 | 原因 / 处理 |
|---|---|
| `login rejected for user [x]: invalid token` | token 抄错，或用户被重置过密钥 |
| `traffic quota exceeded` | 用户流量超额，控制台「清空流量」或调大配额 |
| `reached the max proxy count limit` | 隧道数上限，删旧隧道或调大 `maxProxies` |
| `client exit success` 后反复重连 | 两端 `auth.additionalScopes` 不一致，服务端关掉即可 |
| 面板打不开 | 安全组/防火墙没放行 webServer.port |
| 隧道通了但很慢 | 看用户限速（Kbps）和 proxy 自己的 `bandwidthLimit`，取更小值 |
