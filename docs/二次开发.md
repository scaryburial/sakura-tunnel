# 二次开发与改版

## 构建

```bash
# Linux / macOS
bash build/build-release.sh            # 三平台 + UPX
bash build/build-release.sh --no-upx   # 不压缩
bash build/build-release.sh --targets "linux/amd64"

# Windows
pwsh -File build\build.ps1
pwsh -File build\build.ps1 -NoUPX

# 单平台快速迭代
CGO_ENABLED=0 go build -trimpath -tags noweb -ldflags "-s -w" -o bin/sakura ./cmd/sakura
```

体积优化要点（实测有效）：

| 手段 | 效果 |
|---|---|
| `CGO_ENABLED=0` | 静态链接，去掉 glibc 依赖 |
| `-trimpath -buildvcs=false` | 去构建路径/版本信息残留，顺带缩小 |
| `-ldflags "-s -w"` | 去符号表和 DWARF，20.8 MB |
| `-tags noweb` | 不嵌上游 Vue 面板（我们自带 124 KB 静态页） |
| `upx --best --lzma` | 20.8 MB → 5.87 MB（28%） |

想再往下（约 15 MB / 4.4 MB UPX）要按功能裁：

- QUIC：`server/service.go` 的 `quicListener`、`client/connector.go`、`pkg/util/net/conn.go`
- KCP：`pkg/util/net/kcp.go` 与两端的 kcp 监听
- 虚拟网卡：`pkg/vnet`（wireguard tun + netlink），客户端 `control.go`/`proxy.go` 里的引用
- Prometheus：`pkg/metrics/prometheus` + `server/api_router.go` 的 `/metrics`

## 改名 / 去指纹

1. **产品名**：`pkg/brand/brand.go` 的 `Name`（二进制名、下载路径）、`Title`、`FullTitle`；
2. **面板**：`pkg/webui/dist/index.html` 的 `<title>`、`<link rel="icon">`、页头文案；`style.css` 里的配色变量；
3. **证书**：`transport.tls` 换成自己的证书，别用自签默认值；
4. **端口**：`bindPort` / `webServer.port` 避开 7000/7500 这类默认值；
5. **二进制字符串**：`-trimpath` + `upx`，必要时再加 `garble -literals -tiny`（注意 `-tiny` 会让体积涨到 50 MB，不划算）；
6. **协议特征**：`pkg/msg/` 的字段名与帧类型字节，两端同改即可（改了就不再兼容上游客户端）。

## 加功能时的落点

- **新面板页面**：`pkg/webui/dist/app.js` 加路由 + API 调用，后端在 `server/http/controller_*.go` 加 handler，`server/api_router.go` 注册；
- **新的用户限制维度**（比如并发连接数）：`pkg/userdb` 加字段 + `Check`，`server/control.go` 的 `checkUserPolicy` 里拦；
- **新proxy类型的限速**：确认走 `BaseProxy.GetLimiter()`，`server/proxy/proxy.go` 的 `join` 已经统一处理 TCP/HTTP/UDP；
- **计费对接**：`UserTrafficHook` 已经是单点，换成写数据库/打 HTTP 即可。
